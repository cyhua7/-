核心期中大專案

作業八：【期中大專案】原生 Node.js 電商購物車網站

專案核心：拋棄 Express 框架包裝，手寫 Node.js 原生伺服器。完整實作前後端路由映射、靜態資源 MIME 分流、與 LocalStorage 持久化購物車商務邏輯。

後端架構設計重點 (server.js)

架構依循「精確路徑優先、通用匹配置後」判斷鏈。使用 fs.readFile 異步加載 HTML 並強制覆寫 utf-8，整合 path.extname() 即時動態解析 .css / .js / 圖片，避免瀏覽器黑屏拒看。同時在 /products API 節點手動配置跨域（CORS）頭響應。

實戰踩坑與除錯日誌 (Debug Log)

⚠️ 痛點一：網頁渲染崩潰（黑屏空白）

原因分析： 代碼編輯時誤將 index.html 整個重複拷貝進 cart.html，造成嚴重的巢狀 HTML 結構嵌套（html 內包 html），使得 DOM 樹解析失敗，JS 找不到特定節點。

解決方案： 徹底清除重複結構，回歸唯一且乾淨的標準 HTML5 獨立骨架。

⚠️ 痛點二：靜態資源路由權限過寬攔截錯誤

原因分析： 後端 server.js 將寬鬆條件（如 req.url.startsWith("/")）寫在頂層，攔截了所有精確請求，並賦予錯誤的 MIME 類型（如把 JS 認成 image/jpeg），被瀏覽器安全機制阻擋。

解決方案： 調校判斷鏈順序。最頂層放「精確網頁路徑」，接著是「特定資源目錄」，最底層才是萬用匹配與 404。
