JS 進階核心邏輯

作業六：JS 進階邏輯與高階函數修煉 (10題解)

作業題目：寫出 10 題有關 JavaScript 函數與參數的練習解答。深入函數式程式設計（Functional Programming）與記憶體配置核心觀念。

10題解核心代碼拆解

1. Callback 基礎實作 (mathTool)

將運算邏輯當做回呼函數傳入，達成解耦的目的。

function mathTool(num1, num2, action) { return action(num1, num2); }
mathTool(10, 5, (a, b) => a + b); // 15

2. 立即執行函數 (IIFE)與範疇鎖定

建立獨立區域範疇，鎖定內部變數防全域污染。

(function() { let count = 100; console.log("Count is: " + count); })();

3. 箭頭函數與陣列轉換 (map)

不污染原陣列，批量映射回傳打 8 折新陣列。

const discounted = prices.map(p => p * 0.8);

4. 陣列參數的「破壞性修改」

傳址特性：在函數內操作 arr.pop() 會改動到外層陣列的記憶體實體。

5. 函數回傳函數 (Higher-Order Function)

利用閉包鎖定外層引數，重複調用。

const multiplier = (factor) => (n) => n * factor;
const double = multiplier(2); // double(10) 輸出 20

6. Callback 篩選器 (myFilter)

手寫 filter 邏輯，依據 callback(item) 的布林結果決定留存。

7. 箭頭函數處理物件陣列

const adults = users.filter(user => user.age >= 18);

8. 參數傳址陷阱：重新賦值 vs 修改

a.push(99) 改動原記憶體，外層變更；b = [100] 是將內部參考導向新位址，外層不變。

9. 延遲執行的 Callback

setTimeout(() => console.log(["Task", "Completed"].join(" ")), 2000);

10. 綜合應用：計算總價

將 cart 陣列所有數字先相加（可搭配 reduce），再丟入 discountFunc 回呼函數計算折扣。

作業七：後端資料庫對接與異步錯誤優先回呼 (10題解)

作業題目：寫出 10 題專為 Express 部落格範例程式設計的挑戰題解。打通「資料如何從資料庫流向網頁」與「非同步錯誤優先回呼」的脈絡。

10題解後端邏輯拆解

1. 物件屬性存取

掌握點符號 post.title 與中括號動態 post["title"] 存取。

2. 物件解構賦值 (Destructuring)

模擬 Express 接收 POST 請求資料：

const { title, content } = req.body;

3. 陣列遍歷與字串拼接

首頁生成文章列表：使用 posts.forEach 遍歷並用樣板字串組裝 HTML。

4. 字典與動態參數 (URL Params)

模擬 req.params.id 鍵值對。

5. 實作「錯誤優先」回呼函數 (Error-First Callback)

老師引導補充：Node.js 標準慣例，第一個參數放 err，無錯則傳 null，第二個參數丟出資料。

function fetchData(id, callback) {
    const fakeData = { id: id, status: "success" };
    callback(null, fakeData); // 成功傳出資料
}

6. JSON 字串解析

使用 JSON.parse(jsonStr) 將資料轉回可操作的 JS 物件。

7. 模擬資料庫的查詢行為 (Simulating Database Query)

老師引導補充：模仿 sqlite3 套件 db.get API，讓學生明白匿名回呼函數如何承接內部查到的 row 資料。

function fakeGet(sql, params, callback) {
    const fakeRow = { id: 1, title: "掌握 JavaScript 函數", content: "..." };
    callback(null, fakeRow);
}

8. 樣板字串與三元運算子條件式渲染

const html = `<h1>Welcome, ${user ? user : "Stranger"}</h1>`;

9. 字串切片與前台預覽 (slice)

利用 str.slice(0, 10) + "..." 實作文章大綱摘要。

10. 錯誤優先回呼攔截處理

理解後端不斷出現的 if (err) return ...。若非 admin 則傳入 callback("Access Denied") 並提前 return 中斷防系統崩潰。

核心期中大專案

作業八：【期中大專案】原生 Node.js 電商購物車網站

專案核心：捨棄 Express 框架，純手寫 Node.js 原生伺服器。底層實現靜態資源分流、MIME 類型動態辨識與 LocalStorage 前端購物車持久化。

後端與前端架構實戰

  • 原生 server.js 判斷鏈：精確攔截路徑，利用 path.extname() 辨識 .css (text/css) 與 .js，確保瀏覽器正確解析，開闢 /products API 並解鎖跨域 CORS 響應頭。
  • LocalStorage 購物車持久化：利用 JSON.stringify 與 JSON.parse 序列化快取商務資料，實作流暢的商品精確刪除與動態總計。

實戰開發除錯紀錄 (Debug Log)

⚠️ 痛點一：頁面渲染異常（畫面黑屏空白）

原因： 編輯整合原始碼時，不小心將 index.html 骨架重複嵌套進 cart.html 內部（html 內包含 html），使瀏覽器 DOM 樹解析崩潰。

解法： 全面重構剔除冗餘標籤，回復單一乾淨標準 HTML5 結構。

⚠️ 痛點二：靜態資源路由權限過寬攔截錯誤

原因： server.js 將寬鬆條件判斷（如 startsWith("/")）寫在頂層，攔截了所有精確請求，使資源檔被誤賦予成圖片 MIME 類型（image/jpeg）遭瀏覽器拒絕解析。

解法： 調整判斷鏈順序：「精確網頁路徑」置頂，其次為「特定資源目錄」，通用規則與 404 放最底層。
